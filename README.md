<h1 align="center">Memory Match</h1>
<p align="center">
    A simple card memory game built with Godot 4 and C#.
</p>
Flip two cards at a time to find matching pairs. If the cards match, they disappear. The game continues until all pairs are found.

[Preview](docs/preview.gif)

---

## Features
- Classic memory match gameplay.
- Adjustable grid size for varied difficulty (sizes from 2 to 6 available).
- Randomized card positions for replayability.
- Simple UI with Play and Exit options.

## Tech Stack
- **Game Engine:** Godot 4.3
- **Programming Language:** C#

## Possible Future Improvements
- Add sound effects and background music.
- Add a scoring system based on time and number of attempts.
- Add animations for card flips and matches.
- Create multiple themes or card designs.
- Add a timer for added challenge.
- Include power-ups or special cards for enhanced gameplay.
